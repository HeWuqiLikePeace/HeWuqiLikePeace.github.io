### **VUE：**

在代码中引用静态资源
在Vite中，推荐将静态资源放在public目录或src目录中，并使用正确的引用方式。
​​使用public目录​​：放在public目录下的资源会被直接复制到dist根目录，引用时使用绝对路径（以/开头）即可。例如，将vue.svg放在public目录下，然后在代码中引用：
<img src="/vue.svg" alt="Vue Logo">
构建后，该图片会被复制到dist/vue.svg，并且请求路径为/vue.svg（如果部署在网站根目录则正确）。
​​放在src目录中​​：如果放在src/assets或其他src子目录下，则应该使用模块导入的方式，这样Vite会处理资源并输出到dist/assets中，并生成带哈希的文件名（可缓存）。例如：
<template>
<img :src="vueLogo" alt="Vue Logo">
</template>

<script>
import vueLogo from '@/assets/vue.svg'
export default {
  data() {
    return {
      vueLogo
    }
  }
}

2. 配置base路径
   在vite.config.js中，base选项用于设置公共基础路径。如果你打算将静态网页部署在服务器根路径，则不需要设置（默认为/）。如果部署在子路径（如https://example.com/my-project/），则需要设置：
   export default {
   base: '/my-project/'
   }

4. 更简单的版本（如果只需要基本功能）
<template>
  <div v-html="renderedContent" class="simple-markdown"></div>
</template>

<script>
import { marked } from 'marked';

export default {
  name: 'SimpleMarkdownReader',
  props: {
    content: String
  },
  computed: {
    renderedContent() {
      return this.content ? marked.parse(this.content) : '';
    }
  }
};
</script>

<style scoped>
.simple-markdown {
  line-height: 1.6;
}
</style>
